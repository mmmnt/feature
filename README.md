# Feature

**The quality spine of AI-native delivery.** Feature is the `.feat` execution specification
language and toolchain: a `.feat` file instructs an AI agent how to build a feature, predicts
every observable effect it will produce, and compiles **deterministically** into complete test
suites — zero step definitions, zero glue code, zero LLM in the translation layer. Anything
captured that wasn't predicted is a failure (*prediction inversion*), and `feat verify` keeps
the committed tests byte-locked to the specs in CI.

> Gherkin specifies behavior. **Feat specifies features** — and proves the spec in its original
> form was delivered.

This repository is **built spec-driven on itself**: Feature's own components are specified in
`.feat`, their test suites are generated by `feat generate`, and CI is `feat verify && feat run`.

## Quickstart (in this repo)

```sh
pnpm install && pnpm build

node packages/feature/bin/run.js parse packages/feat-core/parse.feat   # spec → IR
node packages/feature/bin/run.js generate                              # specs → test files
node packages/feature/bin/run.js verify                                # CI gate: byte-locked
node packages/feature/bin/run.js run                                   # execute w/ adapters
node packages/feature/bin/run.js report                                # summarize (JUnit for Xray)
node packages/feature/bin/run.js audit                                 # buildability lint (B1–B3)
```

## The language

- `docs/grammar-reference.md` — the complete `.feat` v1 reference (token classes, four closed
  reference spaces, matchers, seeds, `deliver` triggers, `contains` state assertions, actors,
  clock control, scenario outlines, golden fixtures, the agent contract).
- `corpus/` — nine exemplars, each paired with its expected IR (`.ir.json`): the language's
  ground truth. The corpus grows with every language change, forever.
- `schemas/` — the language-neutral JSON Schema contracts (`builtspec`, `contract`,
  `feat.config`). Validate: `pnpm corpus:validate`.

## Packages

| Package | Role |
| --- | --- |
| `@mmmnt/feature` | The `feat` CLI (parse · generate · verify · run · report · audit · lint · fmt · watch · diff) |
| `@mmmnt/feat-types` | Shared contracts (types only, zero runtime) |
| `@mmmnt/feat-core` | The parser: text → BuiltSpec IR, four closed-space validations |
| `@mmmnt/feat-derive` | IR + config → TestTopology (pure, deterministic) |
| `@mmmnt/feat-emit-ts` | TestTopology → complete Vitest files (deterministic, self-contained) |
| `@mmmnt/feat-runtime` | What generated tests import: harness, adapter loading, `toMatchPrediction` |
| `@mmmnt/feat-runner` | Thin `vitest run` subprocess orchestrator |
| `@mmmnt/feat-adapter-*` | Response/service adapters (`handler`, `http`, `fs`); plain packages exporting `createAdapter(config)` |

## Governance

work). Design decisions are ADRs in the Confluence FEAT space; causal history lives in flmnt.
